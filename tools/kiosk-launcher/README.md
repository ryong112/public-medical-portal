# 공공의료지원과 전광판 네이티브 실행기

전광판 전용 Edge 창을 보조 모니터에 처음부터 무테 전체화면으로 열고, 포털의 접기·다시 열기 요청을 처리하는 Windows용 C# 실행기입니다.

## 보안 구조

- PowerShell, `ExecutionPolicy Bypass`, Base64 내장 스크립트를 사용하지 않습니다.
- 설치, `dphskiosk://` 프로토콜 등록, Edge 실행과 제어창 표시를 C# 코드가 직접 처리합니다.
- F11 키를 전송하지 않습니다. 전용 Edge 프로필의 앱 창을 시작부터 전체화면으로 한 번 실행한 뒤 그 상태를 유지합니다.
- 접을 때는 전체화면 Edge를 숨기고 별도 네이티브 제어창을 즉시 표시하므로 다른 Edge 창에는 영향을 주지 않습니다.
- 관리자 권한이 필요하지 않으며 현재 사용자 영역에만 설치합니다.

## 배포 파일 만들기

프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
powershell.exe -NoProfile -File .\tools\kiosk-launcher\Build-KioskInstaller.ps1
```

완성 파일은 `release\DPHS-Kiosk-Setup.exe`입니다. 다른 PC에는 이 파일 하나만 전달하면 됩니다.

## 설치 및 사용

1. `DPHS-Kiosk-Setup.exe`를 실행합니다.
2. 실행기는 `%LOCALAPPDATA%\DPHSKiosk`에 복사되고 바탕화면 및 시작 메뉴 바로가기를 만듭니다.
3. Edge가 외부 프로토콜 실행 여부를 처음 물으면 항상 허용을 선택합니다.
4. 포털 또는 바탕화면 바로가기에서 전광판을 엽니다.

최초 화면부터 보조 모니터 전체를 채운 Edge 전용 앱으로 표시됩니다. F8을 누르면 전광판은 전체화면 상태 그대로 숨고 작은 네이티브 제어창이 즉시 나타납니다. 다시 F8을 누르거나 제어창 버튼을 누르면 기존 전광판이 즉시 복귀합니다. 전용 프로필을 사용하므로 인증 상태도 다음 실행까지 유지됩니다.

전용 프로필이 아직 승인되지 않았지만 일반 Edge 프로필이 이미 승인된 PC라면, 최초 실행 시 일반 Edge에 자동 인증 탭을 한 번 열어 5분 유효·1회용 요청으로 전광판 프로필만 승인합니다. 전광판에는 관리자 권한이 복사되지 않으며, 차단된 전광판 프로필은 자동으로 다시 승인되지 않습니다.

## 제거

프로젝트 루트의 `uninstall-kiosk-launcher.cmd`를 실행합니다.

## 코드 서명

현재 빌드 스크립트는 인증서가 없는 환경에서도 빌드할 수 있도록 서명 단계를 포함하지 않습니다. 기관용 코드 서명 인증서가 준비되면 최종 EXE에 Authenticode 서명을 추가한 뒤 V3 오진 검사를 진행하는 것이 좋습니다.
