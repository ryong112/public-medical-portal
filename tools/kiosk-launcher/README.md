# 전광판 Windows 실행기

Edge의 팝업 허용 여부와 관계없이 포털의 전광판 아이콘으로 보조 모니터에 전광판을 여는 Windows용 도우미입니다. 전광판은 처음부터 모니터 전체 크기로 열리고, 접으면 작은 `전광판 열기` 창만 남습니다.

## 다른 PC에 설치할 파일 만들기

`tools\kiosk-launcher\Build-KioskInstaller.ps1`을 실행하면 `release\DPHS-Kiosk-Setup.exe`가 생성됩니다. 전광판을 사용할 PC에는 이 EXE 파일 하나만 전달하면 됩니다.

설치 파일은 관리자 권한 없이 현재 Windows 사용자에게 실행기를 설치하고, 바탕화면 바로가기와 `dphskiosk://` 연결을 만듭니다. 연결 완료 안내를 닫으면 설치 프로그램도 자동 종료되며 전광판은 포털에서 버튼을 눌렀을 때만 열립니다.

포털에서 전광판을 열 때는 콘솔 창이 없는 전용 Windows 실행기가 PowerShell을 숨은 상태로 시작하므로 CMD 창이나 작업표시줄 아이콘이 나타나지 않습니다.

## 최초 1회 설정

1. 프로젝트 최상위의 `install-kiosk-launcher.cmd`를 더블클릭합니다.
2. 연결 완료 안내를 확인합니다. 관리자 권한은 필요하지 않습니다.
3. 포털의 전광판 아이콘을 누릅니다.
4. Edge가 `dphskiosk` 실행 허용을 물으면 항상 허용을 선택합니다.

## 사용법

- 처음 열면 보조 모니터에 전체 화면으로 표시됩니다.
- 전광판의 `접기`를 누르면 작은 `전광판 열기` 창으로 바뀝니다.
- 작은 창에서 `전광판 열기`를 누르면 같은 모니터의 전체 화면으로 복귀합니다.
- 전광판의 `X`를 누르면 전광판과 백그라운드 실행기가 함께 종료됩니다.

연결을 제거하려면 `uninstall-kiosk-launcher.cmd`를 실행합니다.
