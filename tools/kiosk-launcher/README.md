# 전광판 Windows 실행기

Edge의 팝업 허용 여부와 관계없이 포털의 전광판 아이콘으로 보조 모니터에 전광판을 열고, 가장자리 손잡이로 숨기거나 복귀하는 Windows용 도우미입니다.

## 최초 1회 설정

1. 프로젝트 최상위의 `install-kiosk-launcher.cmd`를 더블클릭합니다.
2. 연결 완료 안내를 확인합니다. 관리자 권한은 필요하지 않습니다.
3. 포털의 전광판 아이콘을 누릅니다.
4. Edge가 `dphskiosk` 실행 허용을 물으면 항상 허용을 선택합니다.

## 사용법

- `바탕화면 보기`: 전광판 창만 숨깁니다.
- `전광판 열기`: 같은 모니터에 다시 전체 크기로 복귀합니다.
- 손잡이를 위아래로 드래그하면 위치를 조정할 수 있습니다.
- 손잡이를 우클릭하면 좌·우 배치, 다른 모니터로 이동, 종료를 선택할 수 있습니다.

연결을 제거하려면 `uninstall-kiosk-launcher.cmd`를 실행합니다.
